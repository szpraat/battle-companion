# Battle Companion

An unofficial, free fan-made battle companion for Gloomspite Gitz players in Warhammer Age of Sigmar (4th edition): import an army list from the official app, track rounds, phases, abilities and the moon.

**Live site:** https://szpraat.github.io/battle-companion/

Lists and games are saved only in your own browser.
